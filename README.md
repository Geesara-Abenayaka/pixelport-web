# 💻 PixelPort Web Client

PixelPort Web is the modern, responsive web storefront for the PixelPort laptop order management ecosystem. It provides customers and users with an intuitive interface to browse laptop catalogs, compare device specifications, track availability, and place orders.

---

## ⚡ Features

- **Product Catalog:** Browse laptops by brand, processor, GPU, memory, and price range.
- **Specification Overview:** Detailed views for technical specifications and stock status.
- **Order Placement:** Seamless cart and checkout flow for purchasing devices.
- **Order Tracking:** Real-time visibility into customer order states and fulfillment.
- **Fast UI/UX:** Powered by Vite for optimized bundle size and instant hot module replacement (HMR).

---

## 🛠️ Tech Stack

- **Framework / Library:** React
- **Build Tool:** Vite
- **Linting & Code Quality:** ESLint
- **Styling:** CSS / Modern UI components
- **Backend API Integration:** REST API / Prisma backend
